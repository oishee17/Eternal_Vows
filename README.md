# 💍 Eternal Vows : AI-Powered Wedding & Event Management Platform

An all-in-one digital platform designed to simplify wedding planning, guest coordination, photography sharing and vendor management through intelligent automation and collaboration.

## 📖 About the Project

Planning a wedding involves coordinating multiple activities, managing guests, tracking expenses, arranging schedules, hiring vendors and preserving memories.

This platform aims to bring all these activities together in one centralized application.

The **AI-Powered Wedding & Event Management Platform** combines intelligent planning tools, a collaborative digital wedding album and a competitive vendor marketplace to create a smoother and more organized wedding planning experience.

It is designed for couples, wedding organizers, guests, vendors and administrators.

## ✨ Key Features

### 1. 🤖 AI Wedding Planning Assistant

A centralized dashboard that helps couples organize and manage their wedding preparations.

- **Wedding Dashboard:** Track wedding countdowns, guest statistics, upcoming events, pending tasks and vendor quotations.
- **Smart Guest Management:** Add guests, import CSV lists, categorize invitees and manage digital invitations.
- **RSVP Management:** Track guest responses, including attending, not attending and maybe attending.
- **Budget Tracker:** Set budgets, record expenses, monitor vendor payments and visualize spending through charts.
- **Smart Seating Planner:** Generate seating arrangements based on table capacity, family groups, guest preferences and seating restrictions.
- **Itinerary Generator:** Create personalized schedules for ceremonies such as Mehendi, Haldi, Sangeet, Wedding and Reception.
- **WhatsApp Updates:** Send invitations, reminders and itinerary updates through an appropriate messaging integration.

### 2. 📸 Collaborative Digital Wedding Album

A shared photography platform that allows wedding guests to contribute their memories.

- **QR Code Album Access:** Generate unique QR codes for wedding events so guests can access the corresponding album.
- **Photo & Video Uploads:** Upload multiple photographs and videos directly from smartphones.
- **Automatic Categorization:** Organize media into categories such as family, friends, couple portraits, decorations and wedding rituals.
- **Smart Photo Discovery:** Explore photographs using optional AI-powered image recognition features.
- **Interactive Gallery:** Browse images through attractive gallery layouts, previews, filters and slideshow mode.
- **Download & Sharing:** Allow authorized users to download and share wedding memories.
- **Privacy Controls:** Manage album access, upload permissions and participant consent.

### 3. 🏪 Vendor Bidding Marketplace

A dedicated marketplace connecting couples with wedding service providers.

- **Vendor Registration:** Create professional profiles for photographers, caterers, decorators, makeup artists, venues and other service providers.
- **Service Listings:** Showcase services, portfolios, pricing, availability and customer reviews.
- **Wedding Requirements:** Couples can post specific service requirements with dates, locations and budget ranges.
- **Competitive Bidding:** Vendors can submit quotations for available wedding requirements.
- **Bid Comparison:** Compare vendors based on pricing, ratings, services, availability and verification status.
- **Vendor Selection:** Shortlist vendors, communicate with them and accept or reject quotations.
- **Booking Management:** Track accepted quotations and booking status.

## 👥 User Roles

The platform supports four primary user categories:

| User Role | Main Responsibilities |
|---|---|
| Couple / Wedding Organizer | Manage weddings, guests, RSVPs, budgets, seating, itineraries, albums, and vendors. |
| Wedding Guests | Respond to invitations, view schedules, and contribute photographs and videos. |
| Vendors | Manage service profiles, showcase portfolios, submit quotations, and track bookings. |
| Administrator | Manage users, verify vendors, moderate content, and monitor platform activity. |

Artificial intelligence is intended to make wedding planning more efficient and personalized.

Planned AI capabilities include:

- Wedding budget recommendations.

- Automatic categorization of wedding photographs.

The AI assistant will help answer questions such as:

- How should I distribute my wedding budget?
- How many tables will I need for 200 guests?

## 🔐 Security & Privacy

Since the platform handles personal information, wedding photographs and event details, privacy and security are important considerations.

Planned security measures include:

- Secure authentication and role-based access control.
- Protected wedding-specific information.
- Secure QR code access tokens.
- File type and size validation for media uploads.
- Consent-based facial recognition.
- Privacy controls for digital albums.
- Secure storage of API keys and credentials.
- Appropriate data retention and deletion policies.
